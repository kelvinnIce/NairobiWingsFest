# Nairobi Wings Fest landing page

Static, single-file landing page for nairobiwingsfest.com. No build step.

- `index.html` the page (fonts, images and scripts are inlined)
- `favicon.svg` the logo
- `vercel.json` Vercel static config

Placeholders to finish before launch: event date, venue, ticket price, social links, and the sign-up form endpoint (`FORM_ENDPOINT` in the inline script). Until the endpoint is set, the form does not send emails anywhere.
